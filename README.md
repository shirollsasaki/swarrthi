# Swaarthi IAS

What r/UPSC, r/UPSC_Forum and r/upsc_discussions say about UPSC coaching, courses and teachers, set against hand-read reviews from people who paid.

- `index.html` – the full site (single page)
- `<id>.html` – one static page per review, for search engines and link previews
- `cards/` – share images for reviews with enough paid-user data

Not a coaching institute. Not affiliated with any institute.
